# CHRONO-STAR

## Overview
Unityで作成したゲームです。<br>
シンプルな3Dシューティングゲームです。<br><br>
制限時間の中で、降ってくるオブジェクトを打ってスコアを貯めて、高いスコアを目指して下さい。<br>
- 星：スコアが増加
- 爆弾：スコアが減少
- 砂時計：残り時間が増加<br>

ゲーム中にスコアを貯めて、ゲージを貯めるとスキルが使えます。
- ゲージが50%以上100%未満：オブジェクトの落下速度がスローになり、スコアが2倍に増加
- ゲージが100%：オブジェクトの動きが止まり、スコアが5倍に増加<br><br>

**操作方法**
- 左クリック/長押し：選択、弾を発射する
- 右クリック：スキル発動
